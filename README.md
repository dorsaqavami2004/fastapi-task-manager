# پروژه اشتراک‌گذاری عکس و ویدیو با FastAPI

این پروژه یک API برای اشتراک‌گذاری تصاویر و ویدیوهاست که با استفاده از **FastAPI** و ابزارهای مرتبط با پایتون توسعه داده شده است.

## تکنولوژی‌های استفاده‌شده

- Python
- FastAPI
- SQLAlchemy
- SQLite
- FastAPI Users
- JWT Authentication
- ImageKit
- Uvicorn

## قابلیت‌ها

- ثبت‌نام و ورود کاربران
- احراز هویت با JWT
- مدیریت اطلاعات کاربران
- آپلود تصاویر و ویدیوها
- دریافت پست‌ها و فید
- حذف پست‌ها
- اعتبارسنجی و مدیریت درخواست‌ها

## نصب و اجرا

ابتدا مخزن را دریافت کنید:

```bash
git clone https://github.com/dorsaqavami2004/fastapi-task-manager.git
cd fastapi-task-manager
```

نصب وابستگی‌ها:

```bash
uv sync
```

فایل `.env` را در پوشه اصلی پروژه بسازید و متغیرهای محیطی موردنیاز را در آن قرار دهید.

برای اجرای پروژه:

```bash
uv run .\main.py
```

مستندات API پس از اجرا در آدرس زیر در دسترس است:

```text
http://127.0.0.1:8000/docs
```
